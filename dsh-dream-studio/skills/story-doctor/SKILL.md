# 剧本医生

> 只管一件事：**剧本在交到用户手里之前就是对的**，而不是等用户发现问题。
> 格式、资产、出片走 `dream-studio-h3`；镜头可拍性走 `manju-lens`。本技能先于它们执行，管"故事算不算数"。

## 0. 三个账本（没有账本不许开写）

项目 `story/` 目录下维护三份文件，模板见 `references/canon-template.md`：

| 文件 | 记什么 | 什么时候改 |
|---|---|---|
| `canon.md` | 世界规则、人物欲望/缺陷/秘密/说话方式、关系表、禁忌 | 立项写；改人设必须同步 |
| `ledger.md` | 每集结束状态：谁知道了什么、谁拿到了什么、谁欠谁、伤/病/时间/地点、未回收伏笔 | **每集写完立刻** |
| `chain.md` | 集间与场间因果链：上一场的结果 → 这一场的动机 | 每集开写前 |

用户没建账本时，先补账本再写正文；不要一边写一边补。

## 1. 开写前：先读账本，再写第一句

- 上一集 ledger 的结尾状态 = 这一集的开场状态。不许"重置"，不许凭空痊愈、凭空有钱、凭空和好。
- 写之前回答三问，一句话一个：
  1. 这一集开始时，主角最想要什么、最怕什么？
  2. 上一集留下的哪个"未完成"在这里爆炸？
  3. 这一集结束时，谁的处境/认知/关系必须和开始时不同？
- 三问答不出，不要写。

## 2. 因果链：therefore / but，不是 and then

每场先写三行，再写正文：

```
因为〔上一场的结果〕，所以〔本场主角的行动〕；
但是〔阻碍/意外/代价〕；
于是〔结果 + 代价〕，并留下〔新的未完成〕。
```

- 场与场之间只能是"因此"或"但是"，不能是"然后"。
- 一场删掉后剧情不变 → 这场是废场，删。
- 赢也要付代价：时间、秘密、关系、道德、机会，至少一样。
- 主角的关键选择必须有两个以上选项，且他选的是"符合人设但会让自己难受"的那个。

## 3. 人物入场：被需要，不是被安排

- 新人物只能由**在场者已做出的行动**引出：追查、求救、交易、误闯、被牵连。
- 首次登场三件事缺一不可：**他想要什么 / 他挡了谁的路 / 他和主角的关系张力**。
- 主要人物正式登场前，至少一次"被提到、留下痕迹、或别人怕他"。
- 禁止"正好路过""正好听见""正好是失散多年的哥哥"。
- 每个角色有 knowledge state：他知道什么、误以为什么。**角色不能说出他没机会知道的事。**

## 4. 台词：每句都要有目的

四不写：解释（"你也知道……"）、重复（画面已经说了）、客套（你好/多谢）、总结（旁白式台词）。

每句至少占一个：**要东西、挡东西、试探、掩饰、试探底线**。

- 说一半、被打断、答非所问 > 完整陈述。
- 一段 0–15 字（H3 网格），一集 60–120 字；超了就是广播剧。
- 声音指纹：每个主要人物写 3 个特征（句长/称呼/禁用词/口头禅），写台词时对照。
- 潜台词：表面说 A，实际说 B。判据：单独截出来也能感到话里有话。
- 详见 `references/dialogue.md`。

## 5. 交付前：三遍审稿（不许跳）

**第一遍 · 自评**：按 `references/rubric.md` 的 21 项逐条打 pass/fail，每项附一句原文证据。fail 当场改。

**第二遍 · 冷读**：派一个子代理，只给剧本 + rubric，不给创作说明、不给辩解。要求它只报问题、每条引用原文、至少 5 条、指出"观众会在第几段掉线/困惑/不信"。提示词见 `references/critic-prompt.md`。

**第三遍 · 复核**：按冷读结果改，改完再跑一遍 rubric。仍有 fail，不许交付。

**交付时附三段**：这一集的戏眼是什么；我认为最弱的三处；冷读发现并已修掉的问题。用户不该替你找问题。

## 6. 病灶速查

| 症状 | 病因 | 处方 |
|---|---|---|
| 前后接不上 | 没有 ledger | 补状态流水，下一集从结尾状态写 |
| 人物像工具人 | 没有欲望/缺陷 | 回 canon 补，让他做一个对自己不利的选择 |
| 台词像念稿 | 在传递信息 | 改成要/挡/试探，删解释句 |
| 反转不疼 | 反派降智或没埋 | 补铺垫，给反派"他认为自己对"的理由 |
| 中段塌 | 没有回合 | 一个回合两段：挑事 → 打脸/反打 |
| 观众看不懂 | 一场塞了多个新信息 | 一场只给一个新信息 |
| 看了开头不想追 | 没有戏眼/钩子是总结 | 戏眼提前，结尾改成未完成 |

## 7. 与其它技能的分工

- 本技能：故事层（账本、因果、人物、台词、审稿）
- `dream-studio-h3`：格式层（段-格、字段、门禁、资产、出片）
- `manju-lens`：镜头层（13 列、可拍性）
- 顺序：故事 → 镜头 → 出片。**故事不过 rubric，不进段-格。**
