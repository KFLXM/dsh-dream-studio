# 台词诊疗

## 一、先给每句台词贴目的

每句只能贴一个主目的：`[要]` 要东西、`[挡]` 挡回去、`[探]` 试探、`[掩]` 掩饰。

贴不上的句子，删。贴得上但连续三句同目的，合并或删两句。

## 二、四种病，四种改法

### 1. 信息播报（最常见）

❌ "他是青云宗掌门，金丹期修为，我们打不过。"
✅ 师弟往后退了半步，声音压得很低："掌门……出关了。"

改法：把信息拆给**称呼、反应、旁人的害怕**，不要由一个人念设定。

### 2. 情绪直给

❌ "我恨你！你毁了我的一切！"
✅ 她替他理了理衣领，把褶皱一点点抚平："你走的时候，记得把门带上。"

改法：情绪交给动作和日常细节；台词说反话。

### 3. 客套

❌ "多谢救命之恩，日后必有重报。"
✅ "我不欠人了。" 转身就走。

改法：客套换成一个动作，或一句更冷/更狠的话。

### 4. 解释设定

❌ "你也知道，我们家族世代守护这把剑。"
✅ "这剑我守了十年。" 她把剑往桌上一放，"今天不想守了。"

改法：让角色说"自己的处境"，不说"世界的设定"。

## 三、声音指纹

给每个主要人物写三行，写完对照：

```
A：短句（≤8 字）；从不叫对方名字；禁用"请"
B：长句爱绕；每三句一个反问；口头禅"你猜"
C：只说陈述句；生气时反而更客气
```

**遮名测试**：把说话人名字全删，让另一个人读，问"这句是谁说的"。认不出 → 声音没做出来。

## 四、潜台词四招

1. **答非所问**："你昨晚去哪了？" —— "粥在锅里。"
2. **说一半**："其实我就是——"（被打断/自己停住）
3. **把请求说成陈述**：不说"留下"，说"外面雨大"。
4. **用动作代替回答**：不说"我原谅你了"，给她盛一碗饭。

判据：单独截出来，不知道上下文的人也能感到"话里有话"。

## 五、长度与分配

- 一段（4.46–14.38s）：0–15 字，最多两句。
- 一集：60–120 字。超过 150 字，观众开始拖进度条。
- 一段里最多两个人说话；第三个人只用动作或一个短句。
- 单句口播建议 ≤20 字，给配音留呼吸。

## 六、改写练习（写不出来时用）

拿你写的三句台词，依次做：
1. 删掉所有解释句，看剧情还成不成立。
2. 把每句的情绪词删掉，只留动作，看还能不能读懂。
3. 把其中一句改成"说反话"。
4. 把其中一句改成"没说完"。

四步做完还留着的台词，基本就能用了。
