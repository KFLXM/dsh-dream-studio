# 六个高频病灶：诊断与处方

> 每个病灶给三样：怎么确诊（问什么）、处方（改哪一步）、改法示例。
> 顺序就是优先级：先修状态，再修因果，最后修台词。

## 1. 前后接不上（状态漂移）

**确诊**：把上集最后 30 秒和本集前 30 秒并排，列五个事实——在哪、伤/病、手里有什么、谁在场、谁知道什么。对不上的地方就是漂移。

**处方**：
1. 建 `ledger.md`，每集结尾记一次五事实。
2. 本集第一场先"结算"上集的代价（伤要疼、债要还、秘密要漏）。
3. 不许用"过了一段时间"抹掉状态；要跳时间，就交代跳过了什么。

**例**：上集腿中箭 → 本集不能跑；要跑，先给一个"取箭/包扎/被人背"的镜头，或者让他跑一步就摔。

## 2. 人物出场突兀（工具人式登场）

**确诊**三问：
- 谁叫他来的？（在场者做了什么，导致他必须出现）
- 他来之前，主角正在干什么？
- 他不来，这场戏会怎样？

三问答不出，就是"作者需要他"而不是"剧情需要他"。

**处方**：
1. 入场必须由**在场者的行动**引出：追查、求救、交易、误闯、被牵连。
2. 首登场三件事：他想要什么 / 挡了谁的路 / 和主角的关系张力。
3. 正式登场前埋一次"被提到、留下痕迹、别人怕他"。
4. 新人物的作用是**制造新问题**，不是解决旧问题。

**反例**：主角被围，路人突然出手相救，说"路见不平"。
**改法**：改成"主角 earlier 救过的人"（先埋），或者"来人是抓他的"（制造更大麻烦）。

## 3. 逻辑不通（动机缺失 / 信息越界）

**确诊**：
- 给每个关键行动写一句"他为什么**现在**做"。写不出 → 缺动机。
- 列 knowledge 表：这个角色此刻知道什么？每句关键台词的知情来源在哪一场？

**处方**：
1. 动机三选一：欲望驱使 / 恐惧驱使 / 被迫（没有选择）。
2. 补一场"决定"戏：让他明确放弃一个选项，观众才信他选了这条。
3. 信息越界改成"他猜的/他被告知的/他偷听到的/他推断错的"，并让错误推断产生代价。

**例**：他怎么会知道她是卧底？→ 改成"他看见她袖口的印记，误以为她是另一派的人"，误会也能推进剧情，还更真实。

## 4. 台词生硬

**确诊**：随机抽 5 句，问"这句是在传递信息，还是在要东西/挡东西/试探/掩饰？"传递信息超过 3 句 → 有病。

**处方**（三遍过）：
1. 删掉所有解释句，看剧情还成不成立。
2. 每句贴目的标签 `[要][挡][探][掩]`，贴不上的删。
3. 遮名测试：删掉说话人，另一个人读，认不出是谁 → 重写声音。
4. 具体改写见 `references/dialogue.md`。

## 5. 中段塌（没有回合）

**确诊**：中段每两段问一次"这一回合谁赢了？"如果没人赢、或者一直是主角赢 → 塌了。

**处方**：
1. 回合制：**挑事（紧）→ 反打/打脸（松）**，两段一个回合。
2. 每回合换筹码：钱 → 面子 → 秘密 → 人 → 命。
3. 中段至少让主角**真输一次**，输掉的东西后面要用来翻盘。
4. 每个回合结束，观众的"以为"要变一次。

## 6. 结尾没钩子

**确诊**：结尾如果是总结、升华、下集预告、黑屏字幕 → 废。

**处方**：
1. 三种钩子：动作未完成（手伸出去没碰到）、话未说完（被打断）、问题未回答（有人问没人应）。
2. 把最后一句台词删掉，换成一个动作或一个眼神。
3. 钩子要指向"下一集的第一个动作"，不是"下一集的主题"。

## 7. 反转不疼（附）

**确诊**：反转前，观众有没有"以为会怎样"？没有预期就没有反转。
**处方**：先给一个明确的预期（台词/字幕/常识），再让现实反着来；反转后给一个在场者的反应特写。反派必须"认为自己对"，否则打脸不疼。
