# 三个账本的模板

> 账本只记"会改变下一集写法"的事实。不要复述剧情，复述会让账本变成第二份剧本。

## 一、canon.md（立项时写，改人设必须同步）

```markdown
# 《剧名》设定正典

## 世界规则（最多 3 条，写"能/不能/代价"）
1. 能：______  不能：______  代价：______
2. ...
3. ...

## 人物

### 姓名 · 身份
| 项 | 内容 |
|---|---|
| 欲望 | 具体到能落成动作 |
| 缺陷 | 会让他做错事的毛病 |
| 秘密 | 被揭穿会改变关系 |
| 说话方式 | 句长 / 称呼 / 禁用词 / 口头禅（3 个特征） |
| 知识边界 | 他知道什么、误以为什么、绝对不知道什么 |
| 说不出口的那句 | ______（全剧只对一个人说，或永远不说） |

（对手必须多一条：他为什么认为自己是对的）

## 关系表
| A | B | 表面 | 实际 | 什么时候翻转 |
|---|---|---|---|---|

## 禁忌（这部剧不许出现的东西）
- 不许靠巧合解围
- 不许角色说出自己不可能知道的事
- 不许反派降智
```

## 二、ledger.md（每集写完立刻更新）

```markdown
## EP03 · 标题
- 时间/地点：
- 结尾状态：谁在哪、伤/病、持有物、钱/权、谁和谁在一起
- 知情变化：谁新知道了什么（在哪一场、怎么知道的）
- 关系变化：距离/称呼/信任/权力，各自触发点
- 新埋：V-07 玉佩裂纹（计划 EP09 回收）
- 已收：V-03（本集回收，方式：______）
- 未完成：他还没打开那封信 / 她以为他死了
```

规则：
- 伏笔统一编号 `V-xx`，一条一行；回收时改成 `V-03（已收 EP09）`。
- 结尾状态写"事实"，不写"心情"。
- 下一集开场前先读最后一条，逐项对。

## 三、chain.md（每集开写前写）

```markdown
# 因果链

## 集间
EP02 结尾：A 拿到钥匙，但被 B 看见
→ EP03 开场：B 先到一步（因此，不是然后）

## EP03 场内
S1 因为 B 先到，所以 A 改走后门；但是后门锁了；于是 A 砸锁，留下声响（代价：暴露位置）
S2 因为声响，所以守卫来了；但是守卫是 A 的旧识；于是放他走，代价是欠一个人情
...
```

判据：每行都能读成"因为…所以…但是…于是…"。读不成的场，要么重写，要么删。
