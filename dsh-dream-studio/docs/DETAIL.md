# 时空造梦 · 导演台

这个插件是漫剧/短剧的**制作端**。剧本、大纲、人物、段-格脚本这些「写」的活，由配套技能
`dream-studio-h3` 在聊天里完成；插件负责读产出的 `series.json`、管素材库、跑 ComfyUI、
出成片。两边约定了同一份目录结构和门禁，照着 skill 的步骤走就行。

## 谁写哪份文件

| 东西 | 在哪 | 谁写的 |
|---|---|---|
| 画风档位、分集大纲、人物档案、段-格脚本 | `<项目>/第NN集/`、`assets/project.json` | 技能（你在「时空对话」里让它写） |
| 本集 `series.json`（段 → 片段 → 槽） | `<项目>/第NN集/series.json` | 技能跑 `build-series.mjs` 生成 |
| 项目库素材（人物三视图、场景空镜、道具） | `<项目>/assets/` | 插件「导入」落盘，命名规则插件定 |
| 成片 mp4 | `<项目>/assets/<clipId>-<时间戳>.mp4` | 插件出片 |
| 关键帧、草稿、资产重绘 | `<项目>/assets/keyframes/`、`drafts/`、`asset-images/` | 插件 |
| 本集素材 | `<项目>/第NN集/material/` | 插件「导入」 |

> 插件管的目录一律别手改、别挪位置：DB 里存了绝对路径，挪了就断链。要整理只整理输入侧，
> 把原始导出先扔 `_inbox/`，命名后再让插件导入。

## 七步流程（和 skill 里的步骤一一对应）

**1 立项**：和技能确认集数、单集时长、画幅（9:16 / 16:9）、**画风档位**（国漫 3D / 三渲二实机 /
真人写实三选一）。档位写进 `assets/project.json` 的 `style`，不许默认。

**2 人物 + 3 大纲**：技能写 `00_人物档案.md`、`01_大纲.md`。有两道门禁——先给主角/反派小传、
再给前三集大纲，你说「对味」之后它才铺开全集。这一步在「时空剧本」页签直接能看能改。

**4 资产**：把这一集要用的角色、场景、道具条目先写进 `series.json` 的 `assets`。然后：
- 回插件点「**重新扫描**」，剧集库就列出「待生成」；
- 在「时空碎片 → 剧集库」点卡片，右侧写/改提示词，点「生成图片」；
- 图进草稿后点「**入库**」，名字变成 `SC-01_xxx.png` 这种规范名（磁盘名和库里名同步）；
- 状态从 `text` 变 `locked` 之后，下一段才能引用这张图。

**5 写集**：技能先排段表（功能/谁想要什么/被什么挡住/变了什么/钩子式与强度/种子埋收），
再写 `第NN集/剧本.md`，人工过闸后才写段-格（每格十二项：站位/动作/表情视线/持物/本格光/背景/
机位/切续）。这一步不需要插件参与，写完它会跑 `series-lint` 自检。

**6 出帧**：把关键帧提示词给插件，「时空碎片 → 剧集库」出图、入库。每一格的参考图 =
本格出场人物（单人裁切）+ 场景主图（永远挂最后一张）。

**7 出片**：这步在「时空造梦」页签。先让技能按段三选一确认 mode，再跑 `build` 生成 `series.json`；
回插件选片段，右栏调参数，点「生成视频」。

### 三种 mode（制作片段前逐段确认）

| mode | 用在哪 | 参考图 |
|---|---|---|
| **reference**（纯全能参考，推荐） | 默认 | 出场人物图 + 场景主图，无关键帧、无故事板 |
| **reference-keyframe** | 构图和动作断点复杂时 | 在 reference 基础上加四宫格故事板 + 每格关键帧 |
| **frames**（首尾帧 + 故事板） | 必须像素级锁死起止画面 | 首尾两张关键帧，最重 |

**续写判定**：同场景、同人物、接缝机位景别站位不变、时间连续 → `cont: true`，接上一段 latent；
换景/换时/换人/换机位/蒙太奇 → 独立首帧。这条由技能在段表里判，插件只按 `cont` 接 latent。

### 时长网格

每段时长是 `17n+5` 帧 @24fps（n=6..20），即 **4.46–14.38s，共 15 档**。不在网格上插件提交不了；
20 秒的蒙太奇必须拆两段。

## 五个页签

| 页签 | 干什么 |
|---|---|
| 时空剧本 | 直接写本集剧本 / 漫剧大纲 / 人物档案，自动存盘 |
| 时空碎片 | 项目库、剧集库、文生图/图生图/故事板/关键帧生图、草稿入库 |
| 时空对话 | 和 AI 讨论剧情、让它改 `series.json`；聊天里点文件名直接在插件内预览 |
| 时空造梦 | **主工作区**：片段轨、右栏参数、生成视频、独立二采、视频放大/补帧 |
| 时空节点 | 整页嵌 ComfyUI（插件自带同源反代，绕开它的跨源 iframe 拒绝） |

## 出片后的后期

- **独立二采**：读一采 latent，按「二采尺寸 / 重绘幅度 / 二采步数」重绘一遍。**首尾帧（frames）模式
  下不可用**（首帧会糊、关键帧点会飘）；续写段会接上一段的 latent，多要的引导帧自动裁掉，
  段长和原段一致。
- **视频放大 2K / 4K**、**视频补帧**：直接对成片跑，工作流内置。
- **成片历史**：一采、二采、放大、补帧各存一版；点片段卡右上角徽章切版本，URL 带版本号。
- 顶栏「**导出成片**」按集拼成一条 mp4（要 ffmpeg）。

## 设置页

- **ComfyUI 地址**（默认 `http://127.0.0.1:8188`）、**数据根目录**（项目库放哪）。
- **工作流模型**：文生图 / 万能图生图 / 全能 / 独立二采 / 2K 放大 / 4K 放大 / 补帧 七个页签，
  逐个选主模型、文本编码器、VAE、LoRA；改完保存，点「**检查配置**」用 ComfyUI `/object_info`
  校验节点和候选值。
- **MiniMax H3 Context IR API Key**：给技能里的提示词增强接口用，可选。

## 前提

- 本机跑 ComfyUI，装好 H3、Qwen-Image、relay VSR、帧插值这些模型。
- 导出/合并成片要 `ffmpeg`+`ffprobe`（设置里指路径、或 `FFMPEG_PATH`/`FFPROBE_PATH`，或系统 PATH；
  默认包不带二进制，要自带就打包时加 `--ffmpeg`）。
- 技能 `dream-studio-h3` 单独装到 `~/.dsh/skills/`（用户级，全项目可用）；`story-doctor`
  随包带，复制一次：`robocopy skills\story-doctor %USERPROFILE%\.dsh\skills\story-doctor /MIR`。
- 已装过独立预设包 `dsh-preset-studio-assistant` 的，先移除再装合并包（预设 id 会撞）。

## 常见问题

- **进度条停 99%**：采样完还有 VAE 解码和封装 mp4，这段没有步数事件，显示「正在解码出片…」属正常；
  真卡死就重启 DSH（host 代码只在启动时加载）。
- **首帧糊 / 接缝跳**：二采 latent 续写只在「同场景+同人物+同画布分辨率」时才接；上一段一采时长
  不在 H3 网格上会被拒重跑。先按技能的续写判定规则看 `series.json` 里 `cont` 对不对。
- **时空节点白屏**：ComfyUI 跨源 iframe 被拒，插件自带反代；反代没起来会给原因提示。
- **模型下拉是空的**：点「检查配置」，多半是模型不在 ComfyUI 的 `diffusion_models`/`text_encoders` 目录里。
- **改完 `series.json` 插件没反应**：顶栏点「重新扫描」。
